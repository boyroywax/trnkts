# @trnkts/identifier

This package provides a set of utilities for generating and validating identifiers in TypeScript projects.

## Installation

You can install the package using npm or yarn:

```bash
npm install @trnkts/identifier
```

or

```bash
yarn add @trnkts/identifier
```

## Usage

You can import the utilities from the package as follows:

```typescript
import { generateId, validateId } from '@trnkts/identifier';
```
