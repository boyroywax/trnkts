Line Heights

Line Height Variations
Tight line height (1.2) - Good for headings and display text where space is limited. Creates a more compact feel.
Normal line height (1.5) - Default for body text. Provides good readability and comfort for extended reading.
Relaxed line height (1.75) - Creates more breathing room. Good for important content or when you want to slow down reading.

✅ Do
Use consistent scale
Stick to the predefined typography scale for consistency across your design system.
<h1 class="h1">Main Title</h1> <h2 class="h2">Section Title</h2> <p class="body-medium">Body text</p>
❌ Don't
Use arbitrary sizes
Avoid creating custom font sizes that don't align with the established scale.
/* Don't do this */ .custom-title { font-size: 1.73rem; font-weight: 550; }
