Primary Font Family

SF Pro Display

font-family: 'SF Pro Display', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;

SF Pro Display is Apple's system font designed for optimal readability and modern aesthetics. It serves as our primary typeface for all interface elements, headings, and body text. The font stack includes progressive fallbacks to ensure consistent appearance across all platforms and devices.

Monospace Font Family

SF Mono

font-family: 'SF Mono', Monaco, 'Cascadia Code', monospace;

Form Building Guidelines

Typography in Forms

Forms are critical touchpoints in user experience. Consistent typography ensures clarity, reduces cognitive load, and guides users through complex interactions with confidence.

Form Labels

/* Form Labels */ font-family: 'SF Pro Display', sans-serif; font-size: 0.9rem; /* 14px */ font-weight: 600; /* Semi-bold */ color: #333; /* High contrast */ margin-bottom: 0.5rem; /* 8px spacing */

Input Fields

/* Input Fields */ font-family: 'SF Pro Display', sans-serif; font-size: 1rem; /* 16px minimum for mobile */ padding: 0.75rem; /* 12px */ border: 2px solid #e9ecef; border-radius: 8px; /* Focus State */ border-color: #AF4B0E; box-shadow: 0 0 0 3px rgba(175, 75, 14, 0.1);

Placeholder Text

/* Placeholder Text */ font-family: 'SF Pro Display', sans-serif; font-size: 1rem; color: #666; /* Medium gray */ font-weight: 400; /* Regular weight */ /* Be descriptive and helpful */ placeholder="Enter your email address" ✓ placeholder="Email" ✗

Implementation Guidelines

Best Practices

Font Loading

Use the system font stack to ensure immediate rendering and fallback support:

font-family: 'SF Pro Display', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;

Size Scale

/* Recommended size scale */ --font-size-xs: 0.75rem; /* 12px */ --font-size-sm: 0.875rem; /* 14px */ --font-size-base: 1rem; /* 16px */ --font-size-lg: 1.125rem; /* 18px */ --font-size-xl: 1.25rem; /* 20px */ --font-size-2xl: 1.5rem; /* 24px */ --font-size-3xl: 2rem; /* 32px */ --font-size-4xl: 2.5rem; /* 40px */

Line Heights

/* Optimal line heights for readability */ --line-height-tight: 1.2; /* Headings */ --line-height-snug: 1.3; /* Subheadings */ --line-height-normal: 1.5; /* Body text */ --line-height-relaxed: 1.6; /* Long-form content */

Accessibility

  • Maintain minimum 16px base font size for body text
  • Ensure sufficient contrast ratios (4.5:1 for normal text, 3:1 for large text)
  • Use relative units (rem, em) for scalable typography
  • Test readability across different screen sizes and zoom levels
